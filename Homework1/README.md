## 🎯 一、作业目标

本次作业围绕课堂上学习的 **`printf` 输出函数** 与 **C语言基本数据类型** 展开。完成后你应当能够：

| 序号 | 能力目标 |
|:---:|:---|
| 1 | 熟练使用 `printf` 输出文本、数字与字符 |
| 2 | 理解并使用 `int`、`float`、`double`、`char` 四种基本数据类型 |
| 3 | 掌握格式控制符 `%d`、`%f`、`%lf`、`%c`、`%s` 的正确用法 |
| 4 | 会用**域宽**与**精度**（如 `%8.2f`、`%-10s`）让输出**整齐对齐** |
| 5 | 养成规范书写代码、添加注释的良好习惯 |

> 💡 本次作业**不需要**输入（`scanf`）、判断（`if`）或循环（`for`/`while`），所有数据都直接在代码里写死。

## 🧩 四、题目

### 📇 题目1（必做）· 个人信息卡片

**文件：`task1_card.c`**

使用 `printf` 输出一张**属于你自己的个人信息卡片**，要求：

1. 至少包含 **5 行**信息，且必须包含：**姓名**、**学号**、**班级**、**专业**、**一句座右铭**；
2. 使用换行符 `\n` 控制换行；
3. 排版整齐、层次清晰（可以用分隔线或边框装饰）。

**输出示例（内容请替换为你自己的信息）：**

```text
+--------------------------------------+
|           个 人 信 息 卡             |
+--------------------------------------+
|  姓名：张三                          |
|  学号：2604020348                    |
|  班级：26电子信息工程2班             |
|  专业：电子信息工程                  |
+--------------------------------------+
|  座右铭：代码写千遍，其义自见。      |
+--------------------------------------+
```

> 💡 提示：`printf` 中的 `|`、`+`、`-` 都只是普通字符，照原样输出即可。

### 🔢 题目2（必做）· 基本数据类型演示

**文件：`task2_types.c`**

定义并初始化以下 **4 个变量**，然后**每个变量单独输出一行**：

| 变量类型 | 存放内容 | 示例值 |
|:---|:---|:---|
| `int` | 你的年龄 | `19` |
| `float` | 你的身高（单位：米） | `1.75f` |
| `double` | 圆周率 π | `3.14159265358979` |
| `char` | 你的血型 | `'A'` |

**要求：**

1. 四个变量都要**单独定义并赋初值**，变量名要有意义（例如 `age`、`height`、`pi`、`bloodType`）；
2. 使用对应的格式控制符输出：`int` → `%d`，`float` → `%f`，`double` → `%lf`，`char` → `%c`；
3. 每行输出格式形如 `类型  变量名 = 值`；
4. **观察并思考**：为什么 `float` 和 `double` 输出的位数不一样？请把结论写在 `report.md` 里（可选）。

**输出示例：**

```text
int     age      = 19
float   height   = 1.750000
double  pi       = 3.141593
char    blood    = A
```

> 💡 提示：`float` 类型的常量建议加后缀 `f`，例如 `1.75f`。

### 📊 题目3（必做）· 格式化输出练习

**文件：`task3_table.c`**

使用 `printf` 的**域宽**与**精度**控制符，输出一张**对齐的商品价目表**。

**要求：**

1. 至少包含 **1 行表头 + 4 行数据**；
2. 三列内容：**商品编号**（整数）、**商品名称**（字符串字面量）、**单价**（保留 2 位小数）；
3. 对齐要求：

| 列 | 要求 | 控制符示例 |
|:---|:---|:---|
| 商品编号 | 右对齐，占 6 列 | `%6d` |
| 商品名称 | **左**对齐，占 12 列 | `%-12s` |
| 单价 | 保留 2 位小数，占 10 列 | `%10.2f` |
| 表头 | 与数据行**逐列对齐** | `%6s` / `%-12s` / `%10s` |

**输出示例：**

```text
  编号  名称              单价
     1  铅笔              1.50
     2  笔记本            5.80
     3  橡皮              0.75
     4  圆规             12.00
```

> 💡 **关键点**：左对齐用负号 `%-12s`；保留小数位用 `.2`，如 `%.2f`；两者可组合成 `%10.2f`。
> 💡 若你还没学过字符串变量，直接把 `"铅笔"` 这样的**字符串字面量**写进 `printf` 即可。

### ⭐ 题目4（选做·加分）· 单位换算表

**文件：`task4_bonus.c`**

已知 **1 英寸 = 2.54 厘米**。请输出 **1、2、3、4、5 英寸**分别对应的厘米数，保留 **2 位小数**。

**输出示例：**

```text
1 inch =  2.54 cm
2 inch =  5.08 cm
3 inch =  7.62 cm
4 inch = 10.16 cm
5 inch = 12.70 cm
```

**要求：**

- 可以**直接把每一行的结果写成常量**（例如 `2.54`、`5.08`）；
- 也可以使用**乘法表达式**（例如 `2 * 2.54`）来计算——两种写法都接受；
- 数字列请对齐（提示：`%5.2f`）。

> 🚫 本题**不需要**使用循环，逐行 `printf` 即可。
